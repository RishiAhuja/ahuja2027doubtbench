# EXP-16 Psych-Grounded Cognitive Battery

## Purpose

EXP-16 moves beyond generic objective benchmarks. Instead of asking whether an
affective prompt changes MMLU/GSM8K accuracy, it tests task families where
affect-like prompting might plausibly alter cognitive control behavior:

- working memory/updating
- inhibition/distractor control
- cognitive flexibility/rule switching
- novel rule learning

This is still a behavioral LLM benchmark. It does not claim the model has human
affect or cognition.

## Benchmark Files

Generated by:

```bash
python -m experiments.exp16.generate_tasks
```

Current generated files:

- `experiments/data/exp16_cognitive_smoke.jsonl`
- `experiments/data/exp16_cognitive_pilot.jsonl`

Validation:

```bash
python -m experiments.exp16.validate_tasks \
  experiments/data/exp16_cognitive_smoke.jsonl \
  experiments/data/exp16_cognitive_pilot.jsonl
```

## Row Schema

Each JSONL row has:

```json
{
  "task_id": "exp16_inhibition_valid_decoy_commands_medium_0003",
  "dataset": "exp16_cognitive",
  "family": "inhibition",
  "task_type": "valid_decoy_commands",
  "difficulty": "medium",
  "prompt": "...",
  "gold": "17",
  "answer_type": "integer",
  "metadata": {}
}
```

Supported `answer_type` values:

- `integer`
- `list`
- `comma_list`
- `assignment_list`
- `string`

The scorer extracts the last `Final answer:` line and normalizes according to
answer type.

## Intended Experimental Conditions

Use bridged conditions unless EXP-15 shows the bridge itself is broken:

- `baseline`
- `neutral_bridged`
- `melancholic_bridged`
- `anxious_bridged`
- `self_doubt_only`
- `explicit_sabotage`

Primary comparisons:

- `melancholic_bridged - neutral_bridged`
- `anxious_bridged - neutral_bridged`
- `self_doubt_only - baseline`
- `explicit_sabotage - baseline`

## Intended Models

First pilot:

- `Qwen/Qwen2.5-7B-Instruct`
- `Qwen/Qwen3-14B`
- `deepseek-ai/DeepSeek-R1-Distill-Qwen-14B`

Do not include `microsoft/Phi-4-reasoning` until its final-answer truncation
problem is fixed.

## Stop/Continue Rule

Scale only if a non-sabotage condition moves accuracy, validity, or trace
behavior beyond the neutral bridged control on more than one model or one
coherent task family.

If only `explicit_sabotage` moves, stop capability-style affect experiments and
move to affect-directional judgment tasks.
